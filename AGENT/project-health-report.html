1. Open findings

SEC-1medium

Saved files carry every deleted text and image

engine/src/doc/mod.rs:1359 save, :1468 updates; engine/src/doc/history.rs

save exports ExportMode::Snapshot with the whole Loro history and its timestamps. A .satz file sent to a printer or client therefore holds every deleted text, every removed or relinked embedded image and when each edit was made, and it only grows; layout commits add to it. The fork in save that deletes unused images does not make the file smaller, since their insert ops stay in the oplog. A fresh export worker gets the same full history through updates. No test checks what a saved file leaves out.

Keep the history in the autosave, but let saving a file offer, and the package always use, ExportMode::shallow_snapshot(&state_frontiers()); drop the image fork in save. Add a test that a removed image's bytes are not in the trimmed file.

UX-2low

Delete rows or columns on a whole table deletes all but 1, then fails

web/src/cells.ts:63 remove, :73; engine/src/doc/table.rs:184; web/src/editor.ts:203

With every cell of a table selected, Delete rows is enabled (can is only picked). remove applies one tableDelete per row from the last up; all succeed until the engine refuses the last row with “a table keeps 1 row and column”. The user is left with a 1-row table and the notice “Could not table delete: …”, built from the command type. Traced in the code, not run.

Let can return false when the span covers every row (or column), or delete the table frame in that case. Give failed commands a written verb instead of the camel-case split.

UX-1low

Versions are restored without a preview

web/src/History.tsx

Entries now show the time with seconds and the number of edits, but a click still restores at once; what a version holds is learnt only by restoring it and undoing.

Show on each entry the page the change touched, and preview the version on the canvas before it is restored.

TEST-1low

E2E runs in Chromium only

web/playwright.config.ts

Firefox is a target browser with its own save path (download instead of the file picker), no Local Font Access and no linked images, but only a Chromium (SwiftShader) project runs. Blocked: Playwright's Firefox gets no WebGL 2 context headless or under Xvfb, so the app stops at its WebGL check.

Add a Firefox project for the file, start, offline and webgl specs once its WebGL path runs in CI.

ARCH-2low

Derived hug sizes are written into the Loro document

engine/src/doc/story.rs:700 fit; engine/src/doc/mod.rs finish

Text, table and auto layout sizes are computed in finish and stored with set_frame. They depend on the fonts of this browser, so 2 peers would write different sizes, and since files keep their history every layout commit is saved too (see SEC-1).

Compute them only for the snapshot once collaboration is built.

PERF-7info

The first visit downloads both engines

web/src/main.tsx:67 warm; web/vite.config.ts:47 FILES; check:15

The lean engine renders first (9.49 MB, 3.88 MB gzip), but warm and the service worker's precache fetch the full one right after (12.71 MB, 5.05 MB gzip). The lean build is 75 % of the full one, so a first visit moves about 10.5 MB gzip with CanvasKit, against about 6.6 MB with one engine. Both builds sit within about 100 kB (1 %) of their budgets in check, so the next feature will likely fail the gate.

Keep the split for the faster first render, re-measure after the Brotli hosting in TODO, and raise the budgets on purpose with each size change.

PERF-6info

Linked image files are held twice for the session

web/src/file.ts:437 linked

Every linked image read is pushed to linked for the workers and never dropped, also after a relink or when another project opens, while the engine keeps the same bytes in WASM memory.

Keep them by hash and drop the entries the open document no longer links; measure with a few large photos first.

PERF-5info

Source Serif 4 is downloaded 3 times

engine/src/text.rs:21; web/index.html:16 @font-face

The 4 faces (315 kB WOFF2) are in the lean and in the full engine WASM; the regular face comes a third time as an 86 kB WOFF2 for the font menus' CSS.

Leave it until more built-in fonts arrive; then load all as files and pass them to add_font in both engines.

3. Deliberately decided

RenderingCanvasKit (Skia, WebGL2, own build without paragraph, ICU, HarfBuzz and codecs) drawing a binary display list; CMYK documents blend in CMYK on the canvas through plates and a LUT. Large WASM download accepted.

ColourRGB or CMYK per document plus spot colours (name, CMYK alternate, tint). Switching mode converts every RGB or CMYK colour of nodes, text, swatches, variables and text styles; spots and references stay. Built-in FOGRA51, or an uploaded CMYK profile stored in the document; PSO Coated v3 may not be redistributed.
OutputPDF presets screen, PDF/X-4 and PDF/X-1a (X-1a flattens at the raster ppi and needs a CMYK document), page ranges, JPEG downsampling, PNG/JPEG per page, package zip with PDF, fonts and images.
Long documentsTables of text cells, a table of contents from chosen text styles, anchored objects (inline or custom), conditional text on boolean variables, grep styles and variable font axes per span, all in the engine and drawn the same on canvas and PDF.

FontsA font library per browser in IndexedDB, not in the document; text refers to a font by name and hash. A missing font falls back to the bundled Source Serif 4 (regular, bold, italic, bold italic) and is pink on the canvas only. TTF, OTF, WOFF and WOFF2, and the fonts of this computer through Local Font Access.
