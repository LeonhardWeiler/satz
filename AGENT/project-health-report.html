1. Open findings

UX-8low

A refused thread fails silently

web/src/Canvas.tsx onPointerDown (threading branch), onPointerUp

With a loaded out-port, clicking a text frame that already has a previous or next frame makes thread throw, as does a frame on a master threaded with one on a page; the error goes to console.warn, the threading cursor ends and the frame gets selected as if it had worked; a frame drawn from the port stays behind unthreaded. Nothing tells the user why the text did not flow.

Show a not-allowed cursor over frames that cannot take the thread while threading, and keep threading active after a refused click.

PERF-2low

PDF export blocks the UI without feedback

web/src/App.tsx exportPdf; engine/src/lib.rs pdf

Export runs synchronously on the main thread. All pages now print from one snapshot: 42 ms for the threaded 8-page booklet (Node, WASM without wasm-opt). Shadows and blurs rasterised at 300 ppi and, later, images are not measured; a slow export freezes the tab without any sign of progress.

Show a busy state before the call; move export into a Worker once images land.

TEST-5low

Vitest depends on artefacts written by cargo test and wasm-pack

engine/src/display_list.rs test writing web/src/testdata/; web/src/displayList.test.ts; web/src/renderer.test.ts; .gitignore

A Rust test writes display-list.bin/.json into the gitignored web/src/testdata, which the TS decoder test reads; renderer.test.ts needs the wasm-pack output. ./check runs them in the right order, but pnpm test on a fresh clone fails with a missing file, and a test with a side effect on another package is surprising.

Commit the fixture and let the Rust test compare against it (failing with a hint to regenerate), so both sides check the same file; state in the README that pnpm test needs the wasm build.

TEST-1low

E2E runs Chromium only; layer reordering, File System Access and Local Font Access are untested

web/playwright.config.ts, web/e2e/, web/src/file.ts

Only Chromium (SwiftShader) runs, although Firefox is a settled target browser. The only layers drag test drops a group onto its own child and expects nothing to happen; no test reorders layers or moves one into a group by drag. Page reordering has a test. file.spec.ts removes the file pickers and so tests saving and opening the way Firefox does (download and file input); saving into the same file with showSaveFilePicker, the stored handle after a reload, and finding missing fonts with queryLocalFonts run in no test, because both need a native dialog or a permission.

Add a layers drag-and-drop test (reorder, into a group); stub the pickers and queryLocalFonts with handles whose structured clone IndexedDB accepts; add a Firefox project once its WebGL path works in CI.

SEC-1low

GitHub Actions pinned to tags, not commits

.github/workflows/ci.yml

The deploy job holds pages: write and id-token: write; third-party actions are referenced by mutable major tags.

Pin actions to commit SHAs (Dependabot keeps them current).

DOC-1low

No CLAUDE.md

repo root

Non-obvious rules live only in code and TODO: the display list contract between display_list.rs and displayList.ts, the wasm-bindgen pin that must match the flake's CLI, the trash root for undo, the story held by a thread's first frame with next links, master layers drawn under pages with detached/overrideOf, colours keeping their own space, the FOGRA51 build in engine/icc/build, the order in which ./check produces test fixtures.

Run /init and keep it to those points plus ./check.

UX-9low

No favicon: every load logs a 404

web/index.html

The page declares no icon, so the browser requests /favicon.ico, gets a 404 in the console on every load and shows a blank tab icon.

Add a small inline SVG icon as a data: URL in <link rel="icon">.

2. What is already strong

  • gate ./check covers fmt, clippy -D warnings, 176 cargo tests, wasm build, tsc, eslint, 18 vitest tests, build, 84 Playwright tests (locally only the CMYK comparison differs with MuPDF 1.23 outside the flake). E2E helpers wait for the drawn frame, not a fixed delay. CI runs the same script in nix develop, started by hand.
  • test Pixel diff of the live canvas against the exported PDF rasterised by MuPDF, in RGB and CMYK, now per page: a resized second page, a master under a page, threaded text across pages, which is also read back from the PDF as one story, a layer across the spine on both pages of its spread, and the two sides of a master spread.
  • test Engine tests read as specifications (deleting_a_threaded_frame_keeps_its_story_in_the_rest_of_the_thread) and check undo with stable ids after structural commands; text tests cover overflow into the next frame including a hyphenated break.
  • test Every bug from earlier manual rounds has an e2e regression test; e2e locates elements by role and accessible name, which also keeps the labels honest.
  • engine Props and colours are range-checked before the first mutation; the UI keeps no clamps of its own. Page and master commands refuse deleting the last page and duplicate master names.
  • design One display list feeds canvas and PDF; item and layer hashes make picture caching cheap, and stale pictures are evicted each frame.
  • text Rich text on Loro, hypher hyphenation, own Knuth-Plass, columns, insets and baseline grid; threads across pages with an overset marker on the out-port; the caret follows the story into the next frame and page.
  • build Toolchain fully in flake.nix; wasm-bindgen pinned to the CLI version in the flake; 3 runtime web dependencies; CI with contents: read by default.
  • a11y Labelled controls, :focus-visible styles, dialog and tab roles in the picker, aria-current on the shown page; layers and pages lists are one tab stop each with arrow keys, the context menu moves with arrows; a loading screen, a WebGL 2 notice and a start-failure notice, each with an e2e test.

3. Deliberately decided

EngineRust → WASM owns the Loro doc, layout and undo; harfrust, hypher, own Knuth-Plass; krilla for PDF, PDF/X built in-house later.
RenderingCanvasKit (Skia, WebGL2) drawing a binary display list; replaced Vello for GPU effects. Large WASM download accepted.
UIFigma UI3 layout, behaviour and shortcuts (Ctrl for Cmd), dark, English, mm by default. Mask rule follows Figma. Start view fits the page.
ColourRGB or CMYK per document plus spot colours (name, CMYK alternate, tint). Switching mode converts nothing; colours keep their own space. Preview through a built-in FOGRA51 profile; PSO Coated v3 may not be redistributed. User profiles later.
Text weightCanvas text is not thickened to match PDF viewers (TODO B8 closed).
HostingStatic on GitHub Pages, no backend. One document autosaved to IndexedDB; .satz files hold its Loro snapshot without history, saved into the same file in Chromium and downloaded in Firefox.
FontsA font library per browser in IndexedDB, not in the document or .satz; text refers to a font by name and hash. A missing font falls back to the bundled Source Serif 4 and is pink on the canvas only. TTF and OTF; the font picker comes later.
BrowsersChromium and Firefox; Safari best effort.
ScopeM1 excludes PDF/X, components, realtime collaboration, Figma import, font helper, i18n.
