1. Open findings

BUG-9high

Redo of a creating command gives new ids and breaks references

engine/src/doc/mod.rs Doc::apply (Create, AddPage, AddMaster, Duplicate, DuplicatePage, Mask, Group, AutoLayout, Paste); Loro UndoManager

Undo of a command that creates nodes deletes them, and redo creates them again with new TreeIDs. Everything that names the old id breaks: a page loses its master, a thread loses its next, a master override keeps overrideOf on the old id so master layer and override are both drawn, and the UI selection points at nothing. Confirmed natively with a probe: AddMaster + UseMaster, undo ×2, redo ×2 leaves the page without master; two threaded frames, undo ×2, redo ×2 leave them unthreaded; an override after undo/redo names the old id while the master layer has id 42. Delete does not have this problem, because it moves into trash.

Let undo of a creation move the nodes into trash as delete does (or keep the ids on redo), and add an engine test that undoes and redoes AddMaster+UseMaster, a thread and an override.

BUG-1high

Lengths without an upper bound make the engine ask for gigabytes and trap

engine/src/doc/mod.rs Props::check (f64::MAX bounds), TextProps::check, check_frame; engine/src/doc/pages.rs set_page; engine/src/geom.rs pattern; engine/src/raster.rs rasterize; web/src/controls.tsx Field (max = Infinity)

Commands require finite numbers but mostly no maximum: stroke weight, radius, blur, shadow offset, text size, letter spacing, line height, indents, gutter, frame and page size, per-side stroke weights, column rule weight, min height and wrap offsets accept anything up to f32::MAX or f64::MAX. A temporary engine fuzzer (random command sequences, then render, png, inks, pdf and save; removed again) and release-mode probes found three ways to stop the engine: (1) a dashed or dotted stroke makes geom::pattern build room / period dashes with no cap, so a dashed rectangle a few km wide asks for 8 GB inside Doc::render on the main thread, i.e. the whole app traps on an input the W field accepts; (2) a shadow or blur makes pdf::raster rasterize its area at the export ppi with no limit but the page, so on a 5000 × 20000 pt page rasterize asked for 34.7 GB (backtrace rasterize ← plane ← raster ← draw ← pdf), and an A0 page with a full-page shadow already needs about 0.5 GB per plane; (3) a stroke weight of 1e10 pt panics in tiny-skia (alpha_runs.rs:189) in png and inks. In WASM (4 GB) the first traps the editor, the others trap the export worker or, above 4 GB, silently leave the shadow out. In debug builds text size 1e40 trips “text drawn where it was not set” and blur 1e9 overflows i32 in raster.rs:114. In the browser a width of 99999999999 mm was accepted, the ellipse vanished and the preflight said “No issues”. (1)–(3) confirmed natively, (1) not run in the browser.

Give every length one maximum in the check functions and in set_page (e.g. 20000 mm, the limit the view already has; text size 0.1–5000 pt; stroke and blur ≤ the page diagonal), pass the same bounds as max to the fields, cap the dash count in pattern (draw solid above some thousands) and the pixel count in rasterize (lower the ppi of that raster). Add the extremes to a_command_that_fails_leaves_the_document_as_it_was.

BUG-6medium

Grouping a group together with its own child leaves a stray group that undo keeps

engine/src/doc/mod.rs group (also reached by mask and auto_layout), sorted; web/src/Layers.tsx select

sorted keeps a node and its descendants together, so group calls create_at for the new group and then fails in reparent when it moves the parent into itself. The created group stays as a pending op, breaking the rule that a failing command writes nothing (the debug_assert fires only in debug builds; the WASM build is release). In the browser: select a group and one of its children (Shift+click in the layers tree selects a range that includes both), press Ctrl+G: the status shows the error, an empty “Group” appears in the layers tree and Ctrl+Z does not remove it. The same with Ctrl+Alt+M and auto layout. Confirmed natively by the fuzzer and in Chromium.

In group drop every id whose ancestor is also in the list (or reject such a list) before the first write, and add the case to a_command_that_fails_leaves_the_document_as_it_was; a release-mode check of pending_txn after each failing apply (rollback with revert_to) would turn any further such fault into a no-op.

BUG-2medium

A failed autosave is lost without a word and not retried

web/src/file.ts autosave → put

put sets last = state() before it writes and neither awaits nor checks files.put. If IndexedDB refuses the write (quota with large images, private mode, a blocked database), the error ends as an unhandled rejection or a silent transaction abort, the version counts as saved, and the next save waits for the next change. The user believes the work is kept until the reload shows an older document. Not reproduced in the browser; read from the code.

Await the transaction (oncomplete/onerror), set last only after success, and on failure call editor.say once with “Autosave failed: …, save the file with Ctrl+S”.

BUG-10medium

Opened files are not checked like commands

engine/src/doc/mod.rs Doc::load (~1300); engine/src/pdf.rs; engine/src/raster.rs

Doc::load checks the root kinds and the images, but no node values. A file with stroke weight −1 makes the PDF export panic in pdf-writer (content.rs:170), and the following krilla destructor aborts the worker; a page height of 1e308 asks for about 2 TB on render. 600 mutated copies of the sample (meta values changed, deleted, moved): 587 opened and rendered, 12 were rejected cleanly, 1 panicked. Files come from other people, so this is the input path that most needs the checks.

Run the checks of the commands (Props::check, set_page, BUG-1 bounds) over every node in Doc::load and reject or clamp the file before it is shown.

UX-4medium

Alt shortcuts fail on macOS and with AltGr

web/src/keys.ts handleKey, altKey; web/src/commands.ts comboOf; web/src/align.tsx ALIGNS

handleKey and comboOf read letters from e.key. On macOS Option changes the character (Option A is “å”, Option H “˙”), so all 8 alignment shortcuts (Alt A/H/D/W/V/S, Alt Shift H/V), Remove auto layout (Shift Alt A), Use as mask (Cmd Option M is “µ”), Auto fit (Cmd Option C is “ç”) and Frame selection do nothing, and remapping in the settings records the wrong character. On Windows with a German layout Ctrl Alt is AltGr, so Ctrl Alt M gives “µ” and Ctrl Alt Q “@”. Found by reading the code; not tried on a Mac.

Read letters and digits from e.code (KeyA, Digit1) when Alt or Ctrl is held, in handleKey, altKey and comboOf, as App.tsx already does.

BUG-12medium

A broken image or font passes the checks and stops the PDF export

engine/src/image.rs register; engine/src/text.rs add_font; engine/src/pdf.rs:148 doc.finish().unwrap()

image::register reads only the header and add_font only the name table, so damaged files are taken, placed and shown. krilla then fails while it encodes the image or subsets the font, and the unwrap panics, which traps the export worker for every PDF and package of that document, without naming the file. A probe that changed a few bytes of PNG and JPEG files: 140 of 400 were placed and then panicked in the PDF export (“Corrupt deflate stream”); of 400 changed TrueType fonts, 13 loaded, shaped and rendered and then panicked (“failed to subset font: malformed font”). WOFF2 files with changed bytes were all rejected cleanly.

Decode an image fully in register and subset a font once in add_font, rejecting what fails, and return krilla’s error from pdf with the layer it comes from instead of unwrapping.

BUG-13medium

Photos with an EXIF orientation are distorted on the canvas and turned in the PDF

engine/src/image.rs; web/src/renderer.ts:380 createImageBitmap; engine/src/raster.rs; krilla

Neither the engine nor krilla reads the EXIF orientation, so size, aspect, PDF and PNG/JPEG export use the stored pixels, which phones keep turned (orientation 6 or 8). The browser’s createImageBitmap turns the image by default, and the renderer draws that bitmap into the unturned unit square, so the canvas shows a squeezed picture and the export a picture lying on its side. Found by reading the code; not tried with a phone photo in the browser.

Read the orientation in register, swap width and height for 5 to 8 and apply it as the image transform for every output; create the bitmap with imageOrientation: 'none' so canvas and PDF agree.

BUG-14medium

Characters the font lacks print as .notdef boxes

engine/src/text.rs shaping (glyph ids taken as they come); engine/src/doc/draw.rs Problem

There is no font fallback and no preflight problem for a missing glyph: the shaper’s glyph 0 goes into the canvas, the PDF and the raster. A probe set text in the bundled font and found glyph 0 for U+000B (Word’s line break), U+2028 (InDesign’s forced line break), U+000C and U+0000, all of which come in by pasting; Cyrillic, CJK or symbols that a Latin font lacks behave the same. Only \n breaks a line.

Add a preflight problem for glyph 0 (with the character), map U+000B and U+2028 to a line break inside the paragraph on paste and in edit_text, and drop other control characters there.

BUG-17medium

Two tabs overwrite each other's autosave

web/src/file.ts autosave, web/src/main.tsx

Every tab autosaves into the one IndexedDB key doc and nothing tells a tab that another one is open. Tab A renames a layer, tab B opens and restores it, renames another layer and closes, then A changes something: the reload shows A's state, B's rename is gone without a word. Confirmed with Playwright in 2 pages of one context.

Take navigator.locks.request('satz', { ifAvailable: true }) at start; a tab that does not get the lock shows a notice that Satz is open in another tab and does not autosave. An e2e test with 2 pages.

BUG-16medium

Find does not go to a match on another page, and Replace never replaces it

web/src/Find.tsx show, current, replaceOne

show only sets editing; the page stays, because editor.follow turns the page only when the caret leaves the frame. current looks the story up in editor.nodes, which holds the shown spread only, so for a match elsewhere it stays −1: the count stays at “1 found”, Enter keeps editing an unseen frame, and Replace only calls next(1) again. Confirmed with Playwright: duplicate the page, type “Zebra” on page 2, go to page 1, Ctrl+F “Zebra”, Enter. After the last match of a story, replaceOne also goes to the first other story, not the next one.

In show turn to the page of textFrame(m.story, m.at); take the head of the edited story from the snapshot, not from nodes; continue with the first match after m in all's order. An e2e test across 2 pages.

A11Y-1medium

Labels, units and hints in --text-3 stay below WCAG AA

web/src/index.css --text-3 (50 uses), light theme --accent, --bad, --warn

--text-3 is the foreground mixed 50 % into the background. Computed contrast: dark theme 4.0:1 on panels, 3.75:1 on inputs, 3.5:1 on raised rows; light theme 3.0:1. At 11–12 px these need 4.5:1. In the light theme the accent is 2.9:1, errors 3.4:1 and warnings 3.2:1 on the panel.

Raise --text-3 to about 62 % in dark and 68 % in light, and darken the light theme's accent, bad and warn until each reaches 4.5:1; check once with the browser's contrast tool.

PERF-7medium

Every command lays out and measures every text of the document

engine/src/doc/mod.rs Doc::finish; engine/src/story.rs lay_out, fit

After each command finish lays out all pages and shapes every auto-size (hug) text again, even when the command touched one rectangle. Measured in release: SetFrame of a rectangle takes 2.2 ms with 1 page, 5 ms with 16 pages of fixed frames and 33.8 ms with 16 pages and 160 hug texts. Dragging on such a document drops below 30 fps.

Lay out only the stories whose content, style or frames changed (the snapshot already knows the changed nodes), or cache the measured size per story version.

BUG-19medium

A grid count or size without bounds freezes the tab

engine/src/doc/pages.rs set_grids; engine/src/doc/mod.rs baselineGrid; web/src/snap.ts gridSpans, targets; web/src/Properties.tsx grid fields

set_grids only checks count != 0 and size >= 0; the N field has min={1} and no max, Size only needs > 0. gridSpans runs on every canvas draw (renderer.ts) and in targets on every snapping move and loops over all columns or all width / size cells, so a count of 1e8 or a size of 0.001 pt freezes the tab, and the setting is saved and autosaved, so a reload freezes again. A baseline grid of 0.01 pt has the same effect in snap.ts. Read from the code, not run in the browser.

Bound the values in the engine as columns is (≤ 20): count ≤ 100, cell size and baseline grid ≥ 1 pt, and give the fields the same min/max.

BUG-7low

A page of width or height 0 breaks the PDF export

engine/src/doc/pages.rs set_page; engine/src/pdf.rs:98; web/src/Properties.tsx page W/H fields

set_page accepts 0 (“must not be negative”), and the page fields have no minimum above 0. PageSettings::from_wh(width + 2·bleed, …).unwrap() then panics for a page of 0 × 0 or 0 width without bleed, which traps the export worker; preflight shows no issue for an empty page. Confirmed natively, the browser message not checked.

Require width and height ≥ 1 pt in set_page (and the bound of BUG-1 above), set min on the fields, and replace the unwrap with an error.

BUG-3low

A trap while restoring the autosave goes on with a broken engine

web/src/main.tsx restore catch

The catch around editor.load treats every error alike: keep, download, start a new document. A WebAssembly.RuntimeError leaves the engine in an undefined state (wasm-bindgen borrow flags, half-applied state), and the trap handler is only installed after the render, so the user works on in an engine that may fail later. With BUG-1 this path is reachable from normal input: a dashed shape made huge traps the render, the autosave already holds it, and the reload traps again while restoring, so the document ends under doc-unreadable and the user gets a new one.

In the catch, after keeping and downloading, show the “Satz stopped” notice when e instanceof WebAssembly.RuntimeError; the reload then starts clean because the autosave was moved to doc-unreadable.

BUG-4low

A new service worker deletes the cache an open tab still needs

web/sw.js; web/src/file.ts new Worker(new URL('./exportWorker.ts', …))

install calls skipWaiting, activate deletes every other cache and claims the clients. A tab opened before a deploy creates its export worker only on the first preflight or export, under the old hashed name; that file is no longer in any cache nor on GitHub Pages, so preflight and export fail until a reload. Read from the code, not reproduced.

Drop skipWaiting and clients.claim so the new version takes over on the next load, or keep the previous cache until no client uses it.

BUG-5low

A second job on the same worker takes over the first one's answer

web/src/file.ts run

run assigns w.onmessage and w.onerror per call. If a call starts before the last one answered (preflight closed and opened again during a preview, so the new effect is not busy), the first answer resolves the second promise and the first promise never settles. The effect is a stale ink preview until the next change.

Queue jobs per worker (chain on the previous promise) or tag each message with an id and resolve by id.

UX-3low

PERF-3low

Every command serialises the whole snapshot to JSON and the UI parses it again

Since 202582b the engine rebuilds only the pages a change reaches, but Engine::snapshot still returns all pages, masters and stories as one JSON string, and Editor.change parses it and rebuilds the node index after every command, on every drag move too. PERF-4low

Unicode character names cost about 277 kB gzip at every start

The engine WASM is 8.3 MB, 3,333,977 bytes with gzip -9 on e554868. A build without unicode_names2 measured on 05.10 was 277 kB gzip smaller: 8 % of the engine for the search by name in the characters panel, which few sessions open.

PERF-6low

The image registry grows for the whole session

engine/src/image.rs IMAGES, adjusted, id, entry_by_hash

The thread-local registry is a Vec that is only appended to: the bytes of every image of every document opened in the tab stay, and adjusted adds one entry per brightness, contrast or saturation value used (forget drops the decoded pixels, not the entries). id and entry_by_hash scan linearly. Dragging an adjustment slider over its range on one image adds about 100 entries. Read from the code, not measured.

Key the registry by hash in a HashMap, keep only the newest adjusted entry per source image, and drop the entries the loaded document no longer references when a document is opened.

BUG-11low

BUG-15low

UX-6low

Step over Intl.Segmenter grapheme segments, as words already do, and on macOS use Option for words and Cmd for line ends.

UX-7low

Show the section label (the engine has Section::label) in the overview and layers, and read it in pagesOf, with the physical number as fallback.

BUG-18low

BUG-20low

A gradient without stops panics the PDF export

Command::Set accepts a linear or radial fill with stops: []; the check only looks at at and the colours of the stops that exist. The PDF export then panics in krilla (index out of bounds) and aborts the worker. The UI always makes 2 stops, so it is reached through a loaded, pasted or imported document. Confirmed natively.

Require at least 2 stops for linear and radial fills in the check.

BUG-21low

Stops out of order make an invalid PDF

web/src/Paints.tsx stop position field; engine/src/style.rs paint; krilla

Stop 1 can be set to 80 % and stop 2 to 20 %; nothing sorts them. krilla writes /Bounds [.8 .2], MuPDF reports “subfunction 1 boundary out of range”, and other readers draw it differently from the canvas, where Skia clamps the positions to be monotonic. Confirmed with mutool.

Sort the stops by position (stable) in the engine before drawing and exporting, or in the check.

BUG-22low

A negative gap on a hug frame fails with a raw error

engine/src/doc/mod.rs gap check; engine/src/layout.rs arrange; web/src/AutoLayout.tsx gap field

The gap accepts any finite value and the field has min=-Infinity. A gap of -200 on a hug frame makes arrange compute a negative size and the command fails with “width and height must not be negative”; later shrinking a child of a frame with gap -20 fails the same way. Confirmed natively.

Clamp the hug size of an auto layout frame at 0, or reject gaps below -(smallest child size) with a message that names the gap.

BUG-23low

Toggling an OpenType feature copies the first span's features to all

web/src/Text.tsx toggle

toggle builds the new feature list from spans[0].features and applies it to the whole range. With a selection whose spans have different features, switching one feature replaces the features of all other spans with those of the first.

Add or remove only the toggled tag per span (a format per run, or an engine command that sets one feature).

UX-8low

Gradient stops cannot be added or removed

web/src/Paints.tsx

A gradient always has the 2 stops retype made; the list shows them but offers no add or remove, so a three-colour gradient is only possible through a file.

Add + and − to the stops list.

UX-9low

The text panel reflects the whole story, not the selection

web/src/Text.tsx TextSection; web/src/Quick.tsx

The panel takes same() over all spans of the story. With a uniformly formatted selection inside a mixed story it shows “Mixed”, while a change applies to the selection only.

Use the spans inside the editor's text selection when there is one.

UX-10low

A recorded shortcut silently takes the keys of another command

web/src/Help.tsx assign; web/src/App.tsx remap

assign stores any combo without checking whether another command already uses it. remap then sends the keys to the reassigned command, and the command whose default it was can no longer be reached by keyboard, with no hint.

When the combo is taken, say which command has it and swap or ask before assigning.

PERF-8low

Text spans clone the node JSON per delta segment

engine/src/draw.rs spans

spans clones the whole node JSON for each segment of the Loro delta. A keystroke costs 1.3 ms at 39 k characters, 4.1 ms with 400 runs and 11 ms with 1500 runs (release, native). Adds to PERF-3.

Borrow the node props and clone only the attributes of each segment.

PERF-9low

PNG and JPEG export allocate page-size pixmaps per layer and shadow

engine/src/raster.rs render

Each layer with opacity, blend or effect and each shadow gets its own pixmap the size of the page. At 300 ppi an A4 page with 1 shadow exports in 0.5 s, with 30 small shadows in 14.1 s (release, native).

Crop the pixmaps to the layer's extent plus blur, as pdf::raster does.

PERF-10low

The CMYK canvas computes the plates on every frame

web/src/renderer.ts draw; engine/src/draw.rs plate

In a CMYK document draw asks the engine for 2 plates per visible page on every pan and zoom frame; nothing caches them between frames where the page did not change. Read from the code, not measured.

Cache the plates per page and snapshot version and only rasterize again when the page or the zoom bucket changes.

DOC-2low

Doc comments above the wrong declaration

engine/src/doc/pages.rs above Guides; web/src/Canvas.tsx near angle, the ruler, flowing, textUnder, guideOf; web/src/Properties.tsx textBelow

Several comments describe a neighbour: the layout grid comment sits on top of Guides, “Snaps a vector to 45°” is stacked over angle, “The page of pages under p” over flowing, “The path of layers at p” over textUnder, a port comment over guideOf, and the comment for DocumentSection over textBelow. Editors then show the wrong hover text.

Move each comment to its declaration or delete it where the declaration it described is gone.

SEC-1info

No content security policy

web/index.html

GitHub Pages sends no security headers and the page sets no CSP meta tag. Risk is small: no backend, user files are parsed by Rust and CanvasKit, no user HTML is rendered.

Add <meta http-equiv="Content-Security-Policy"> with default-src 'self'; script-src 'self' 'wasm-unsafe-eval'; img-src 'self' blob: data:; style-src 'self' 'unsafe-inline' and run the e2e suite against it.

PERF-5info

Source Serif 4 is downloaded twice

engine/src/text.rs:17 FONT; web/index.html:16 @font-face

The default font is in the engine WASM and again as a 262 kB TTF for the font menus' CSS.

Leave it until more built-in fonts arrive; then load all as files and pass them to add_font.

BUG-8info

The service worker cache name ignores the content of public files

web/vite.config.ts service-worker plugin; web/sw.js

The cache name is a hash of the file names only. Bundled files carry a content hash in their names, but manifest.webmanifest, the icons and index.html do not, so a deploy that changes only those keeps the old cache name and installed clients, served cache-first, never see the change.

Hash the file contents (the bundle's source/code and the public files) into the cache name.

ARCH-3info

Auto layout sizes drift on each load

engine/src/doc/mod.rs Doc::finish; engine/src/layout.rs

After save and load, auto layout sizes differ by about 1e-13 pt, so finish writes layout ops on every load and the reloaded document is not equal to the saved one. Harmless for output, but it makes save/load comparisons need a tolerance and marks documents as changed.

Round derived sizes (for example to 1e-6 pt) before writing, or skip the write when the change is below that.

ARCH-4info

sameOf exists twice

web/src/Properties.tsx; web/src/Text.tsx

Both files define the same sameOf.

Keep the exported one in Text.tsx and import it.

PERF-11info

The package zip deflates already compressed files

engine/src/zip.rs; engine/src/draw.rs package

Every entry is deflated at level 6, also JPEG, PNG and font files; 50 MB of incompressible data take 1.5 s for no gain. Only the package export uses it.

Store images and fonts with method 0.

EngineRust → WASM owns the Loro doc, layout and undo; harfrust, hypher (de, en, fr, it, es, nl), own Knuth-Plass; krilla writes the PDF, pdfx.rs adds the PDF/X OutputIntent, XMP and Info.
RenderingCanvasKit (Skia, WebGL2) drawing a binary display list; CMYK documents blend in CMYK on the canvas through plates and a LUT. Large WASM download accepted.
UIDesign G: fixed top bar, layers and swatches left, properties or preflight right, rulers, no floating panels; Figma behaviour and shortcuts (Ctrl for Cmd), dark and light, English, mm by default.
ColourRGB or CMYK per document plus spot colours (name, CMYK alternate, tint). Switching mode converts every RGB or CMYK colour of nodes, text, swatches, variables and text styles; spots and references stay. Built-in FOGRA51, or an uploaded CMYK profile stored in the document; PSO Coated v3 may not be redistributed.
OutputPDF presets screen, PDF/X-4 and PDF/X-1a (X-1a flattens at the raster ppi and needs a CMYK document), page ranges, JPEG downsampling, PNG/JPEG per page, package zip with PDF, fonts and images.
Text weightCanvas text is not thickened to match PDF viewers.
HostingStatic on GitHub Pages, installable and offline through a service worker, no backend. One document autosaved to IndexedDB; .satz files hold its Loro snapshot without history, saved into the same file in Chromium and downloaded in Firefox.
FontsA font library per browser in IndexedDB, not in the document; text refers to a font by name and hash. A missing font falls back to the bundled Source Serif 4 and is pink on the canvas only. TTF, OTF, WOFF and WOFF2, and the fonts of this computer through Local Font Access.
BrowsersChromium and Firefox; Safari best effort.
