1. Open findings

BUG-8medium

Arrow keys in the colour picker also move the selected layer

web/src/ColorPicker.tsx step; web/src/App.tsx onKey; web/src/Canvas.tsx isTyping

The saturation area is a focusable div role="slider". step only calls preventDefault; the window listener in App does not check defaultPrevented, and isTyping only matches inputs, so every arrow press changes the colour and nudges the selection by 1 mm (10 mm with Shift) in the same undo history.

Skip handled events in App.onKey (if (e.defaultPrevented) return); covers every widget that consumes its own keys.

PRINT-1medium

Spot swatches may share a name with different alternates

engine/src/color.rs Swatch::check; engine/src/pdf.rs color; web/src/Swatches.tsx add

Names are not unique; the default name Swatch {n+1} repeats after a delete. The PDF writes one Separation per use with the swatch's name, so two spot swatches called the same with different CMYK alternates produce one plate name with conflicting alternates. Which one the RIP uses is undefined.

Reject a spot name already used by another swatch in AddSwatch/SetSwatch, and derive the default name from the highest existing number.

BUG-5medium

Dropping a layer into its own descendant throws

web/src/Layers.tsx over, onDrop; engine/src/doc.rs Command::Move

over only rejects the dragged rows themselves. Dragging an expanded group onto one of its children (into, above or below) sends a move whose target parent is inside the moved node; Loro rejects the cyclic move, the JsError escapes the drop handler and the drop indicator stays visible.

Reject targets inside a dragged subtree in over, and check ancestry in Command::Move before the first mov_to.

BUG-6medium

Text content and swatch name are stale after undo and re-apply the undone value

web/src/Properties.tsx (Text textarea); web/src/Swatches.tsx (Name input)

Both are uncontrolled with defaultValue and keyed on the id only. After Ctrl+Z restores an older value, the box still shows the newer one; the textarea compares against the restored text on blur and sends setText again, silently redoing the edit.

Key both on id and value, or keep a draft like Field does.

ROB-1medium

Commands are not atomic and engine errors leave the UI stale

engine/src/doc.rs apply; web/src/editor.ts apply

Props are now checked before mutation, but Move, Ungroup and Order still loop over several ids and return Err after partial mutation without commit, so half-done ops land in the next command's transaction. Editor.apply throws before it re-reads the snapshot, so the UI shows a state the engine no longer has (BUG-5 is one way in).

Validate all inputs before the first mutation in each command; in Editor.apply re-read the snapshot in a finally.

PERF-1medium

Full snapshot and full text layout on every event

engine/src/doc.rs render, hit; web/src/editor.ts; web/src/Canvas.tsx

Each setFrame of a drag serialises the whole document to JS (once per selected node), render builds it again for the display list and reshapes and re-breaks every text item per frame, and every hover pointermove calls hit, which builds another full snapshot. Engine.pdf builds one snapshot per page. Fine for the demo page; it will not hold for the 8-page booklet with threaded text.

Cache text layout per node keyed by text, size and frame; render and hit test from one cached tree that commands invalidate; one setFrames command for multi-node drags.

PERF-2medium

PDF export blocks the UI; raster ppi has no upper bound

web/src/App.tsx exportPdf; engine/src/doc.rs SetDocument; engine/src/pdf.rs raster

Export runs synchronously on the main thread without feedback. rasterPpi only has to be positive: at 800 ppi a page-sized A2 shadow is ≈ 13 229 × 18 709 px (≈ 990 MB per buffer, two planes plus a recoloured copy in CMYK), which exceeds the WASM heap and traps the engine; the app is then dead with no message and, without persistence, the work is lost.

Limit rasterPpi in SetDocument (e.g. 72..=1200) like the other props; show progress, later move export into a Worker.

UX-1medium

Blank screen while ≈ 5.4 MB of WASM load, and on load failure

web/src/main.tsx, web/index.html

Build output: engine_bg.wasm 2.4 MB gzip (was 2.1, the FOGRA51 profile is embedded), canvaskit.wasm 3.0 MB gzip. Nothing is rendered until both are initialised; if the fetch or init fails, the top-level await rejects and the page stays empty. This is the first impression of the live portfolio build.

Static loading text in index.html; catch the init promise and render the same notice style as the WebGL message.

TEST-1medium

E2E runs Chromium only and skips the layers panel

web/playwright.config.ts, web/e2e/

Only Chromium (SwiftShader) runs, although Firefox is a settled target browser. No test drags, drops or renames in the layers panel, which is how BUG-5 went unnoticed.

Add a layers drag-and-drop test with the BUG-5 case; add a Firefox project once its WebGL path works in CI.

BUG-9low

Clicking a panel while drawing with the pen splits the path's undo step

web/src/editor.ts gesture; engine/src/doc.rs BeginUndoGroup

The pen keeps an undo group open until the path is finished. A pointerdown in Properties or Swatches sends beginUndoGroup, which ends every open group first, so the rest of the path lands in separate undo steps and Ctrl+Z afterwards removes only the last anchors.

Finish the pen in gesture (as undo already does), or skip the gesture group while editor.pen is set.

UX-6low

Colour picker stays put when the properties panel scrolls

web/src/Popover.tsx

.properties scrolls (overflow: auto); Popover re-places only on window resize and its own size change, so scrolling with the wheel detaches the picker from its row.

Also re-place on scroll (capture) in the same effect.

UX-7low

A click on a swatch in the Swatches panel does nothing

web/src/Swatches.tsx (onPick={() => {}})

Rows look and announce as selectable options, but a single click neither selects nor applies; editing needs a double-click, which is not discoverable. InDesign applies the swatch to the selection on click.

Click applies the swatch to the selection's fill (or opens the editor when nothing is selected); double-click edits.

A11Y-1low

Layers tree has tree roles but no tree keyboard behaviour

web/src/Layers.tsx

role="tree"/treeitem promise arrow-key navigation, but every row is a separate tab stop and reordering is drag-and-drop only. As the canvas has no keyboard access, the layers panel is the only way to reach objects without a mouse.

Roving tabindex with Up/Down/Left/Right on the tree; the existing [/] shortcuts already cover reordering.

A11Y-2low

Space cannot activate focused buttons

web/src/Canvas.tsx onKey

The window-wide Space handler for panning calls preventDefault on keydown and keyup unless an input has focus, so layer rows, add/remove, eye and tab buttons react only to Enter.

Only take Space when the target is the canvas or the body.

MEM-1low

A new typeface per text size, never freed

web/src/renderer.ts font

Item and layer pictures are now evicted. font() still copies the 262 kB font file into a new Typeface for every distinct size and deletes neither typeface nor unused fonts until unmount.

One typeface per font id; Font objects per size are cheap.

ARCH-1low

All pointer logic lives in one untested effect

web/src/Canvas.tsx

Handle detection, line ends, resize maths, marquee, drawing and pen sit in a single ≈ 400-line useEffect. None of it has unit tests, unlike select.ts and pen.ts; only e2e covers it.

Move handleAt and the resize computation into a pure module with vitest cases.

SEC-1low

GitHub Actions pinned to tags, not commits

.github/workflows/ci.yml

The deploy job holds pages: write and id-token: write; third-party actions are referenced by mutable major tags.

Pin actions to commit SHAs (Dependabot keeps them current).

DOC-1low

No CLAUDE.md

repo root

Non-obvious rules live only in code and TODO: the display list contract between display_list.rs and displayList.ts, the wasm-bindgen pin that must match the flake's CLI, the trash root for undo, the Figma mask rule, colours keeping their own space, the FOGRA51 build in engine/icc/build.

Run /init and keep it to those points plus ./check.

UX-5info

Start zoom shows 127 %

web/src/renderer.ts fitView (bugs.md 16, not answered in TODO)

The page is zoomed to fit the window; 127 % is the fit value for the A5 page at that window size. This matches Figma. Shift+0 gives 100 %.

Keep fit; note the answer to bugs.md 16 so it is not reported again.

PRINT-2info

Blurred and shadowed spot colours print as process

engine/src/pdf.rs raster

Shadows and blurs of CMYK documents become one CMYK image; spot inks are converted through their alternate, so that part of the artwork is missing from the spot plate. Expected for rasterised effects, but the user gets no hint.

Report it in preflight (TODO item 15) next to RGB content in CMYK documents.
