7. Beim Umbau gefunden: Datei öffnen ging ohne File System Access API manchmal verloren

behoben

Mit fullyParallel liefen die beiden Beispiel-Tests (Poster, Booklet) erstmals gleichzeitig und scheiterten in CI und lokal in ≈1 von 4 Runden. Zwei Ursachen, beide mit Instrumentierung nachgewiesen:

  • App-Bug: open, addFonts und placeImages legten ein <input type="file"> an, das nirgends hing. Der Garbage Collector konnte es einsammeln, bevor der Nutzer wählte; dann feuerte change nie. Mit erzwungenem GC scheiterten 4 von 4 Läufen. Trifft echte Nutzer in Firefox. Fix: ein modulweites Input für alle drei Picker in web/src/file.ts.
  • Test-Race: page.waitForEvent('filechooser') schaltet das Abfangen in Playwright ohne Rückmeldung ein; unter Last kam Strg+O vorher an, Chrome öffnete einen echten Dialog und brach ihn nach 0,7 ms ab. Fix: open() in web/e2e/util.ts registriert vor dem Laden einen filechooser-Listener. Danach 15 von 15 Stressrunden grün.
