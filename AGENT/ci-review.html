2. Jeder Test rastert ein 1448×1160-Fenster in Software

nicht gemessen

open() setzt das Fenster auf 1448×1160, damit eine Doppelseite bei fester Zoomstufe passt; die Koordinaten aller Tests hängen daran. SwiftShader rastert jede Fläche auf der CPU. Ein halb so großer Canvas wäre grob halb so viel Rasterarbeit, aber jede Bildschirmkoordinate in den Tests müsste neu stimmen.

Fix: Erst angehen, wenn 4 Shards nicht mehr reichen. Dann open(page, width) mit kleinerer Höhe und die Tests über screen() laufen lassen, das schon in mm rechnet.
